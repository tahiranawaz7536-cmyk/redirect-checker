Frequently Asked Questions
The tool performs recursive network requests to trace the complete HTTP redirect sequence from an origin URL to its final destination. It measures individual hop latency, HTTP status codes, and detects potential redirect loops or configuration issues.
A 301 status code indicates a permanent redirect, meaning search engines will pass ranking equity to the new target. A 302 code represents a temporary redirect, signaling to bots that the original URL should remain indexed.
A redirect loop occurs when URL A redirects to URL B, which in turn redirects back to URL A (directly or indirectly). Browsers stop processing after a threshold to prevent infinite rendering cycles.
Cloudflare processes edge redirects via Dynamic Redirect Rules, Page Rules, or Cloudflare Workers. These execute at the edge network before hitting your origin server, resulting in lower latency times.
